\section*{Data availability}

The benchmark artefacts are prepared for archival in a single Zenodo record
under DOI~\texttt{<DOI>}. The record will contain exactly two files: the
versioned code and result archive, and the derived data archive containing
masked label matrices, three sparse genomic feature representations, lineage
assignments, public BioSample accessions and fixed train/validation/test
assignments for the four protocols. The code is licensed under the MIT
License. The derived data are licensed under CC BY 4.0 and were transformed
from CABBAGE release \texttt{2025-11}; the upstream tables, assemblies and
annotations are not redistributed. A full dataset citation and verified
repository URL must be inserted once the DOI and code release are public.
